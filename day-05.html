What is it?

JavaScript is the language of browser behavior

It is a programming language that runs in the browser (and also on servers). It stores data, makes decisions, and later talks to the page.

Why we need it

Users click, type, and expect results instantly — without a new page for every calculation.

How it works

The browser reads your script, executes it top to bottom, and keeps values in memory.

Real world

Google search suggestions, YouTube play/pause, and checkout totals are JavaScript.

What is it?

A variable is a named box for a value

Programs remember things: a name, a total, a list of marks. Variables are those memories.

Why

Without names, you retype numbers and make mistakes.

How

Declare → assign → use. let total = 0;

Real world

Cart total, logged-in username, current slide number.

Operators

Tools that combine and compare values

Math

+ - * / %

10 % 3  // 1 remainder
2 ** 3  // 8

Compare

Always prefer === and !==

5 === "5"  // false
5 ==  "5"  // true — avoid

Logical: && and, || or, ! not. Assignment: = += -=

Strings

Text is data too

Names, emails, error messages — almost every UI is strings.

const first = "Ada";
const last = "Lovelace";
const full = first + " " + last;
console.log(full.length);
console.log(full.toUpperCase());
console.log(full.includes("Ada"));

Numbers

Marks, prices, and averages

const math = 80;
const english = 90;
const total = math + english;
const average = total / 2;
console.log(average); // 85

Watch this trap

"10" + 5 becomes "105" because + concatenates strings.

Fix: Number("10") + 5 or Number(input.value).

Demo prompt() or a fake string from an input. Students hit this on the mini project.

Boolean

Yes / no decisions

Every if needs a true or false. Comparisons produce booleans.

const passed = average >= 40;
const honor = average >= 80 && passed;
console.log(passed, honor);

Why

UI hides, shows, enables, and warns based on yes/no.

How

Comparisons and logical operators.

Real world

“Is the cart empty?” “Is the user logged in?”

Arrays

A list in one variable

Marks for five subjects should not be five separate variables if you want to loop them.

const marks = [80, 72, 90, 65, 88];
console.log(marks[0]);      // 80 — first item
console.log(marks.length);   // 5
marks.push(70);              // add at end

Why

Order and count matter: playlists, todos, products.

How

Index starts at 0. .length is the count.

Real world

A cart is an array of product objects.

Objects

A thing with labeled properties

A student is not a list of random numbers. A student has a name, marks, and a grade.

const student = {
  name: "Karim",
  math: 78,
  english: 82
};
console.log(student.name);
console.log(student["math"]);

Arrays are ordered lists. Objects are labeled records. You will combine both: an array of student objects.

Conditionals

If this is true, do that

const average = 73;
let grade;

if (average >= 80) {
  grade = "A";
} else if (average >= 70) {
  grade = "B";
} else if (average >= 40) {
  grade = "C";
} else {
  grade = "F";
}

Order matters. Check the highest band first so 85 is A, not C.

Ask: what grade is 70? Walk the branches out loud. Then change 70 to 69.

Loops

Repeat work without copy-paste

const marks = [80, 72, 90];
let total = 0;

for (let i = 0; i < marks.length; i++) {
  total += marks[i];
}

const avg = total / marks.length;

Also useful

for...of reads “for each item in the list”:

for (const mark of marks) {
  total += mark;
}

Functions

A reusable recipe with a name

If you compute a grade in three places, you will get three slightly different bugs. Put the recipe in one function.

function getGrade(average) {
  if (average >= 80) return "A";
  if (average >= 70) return "B";
  if (average >= 40) return "C";
  return "F";
}

console.log(getGrade(73)); // "B"

Functions · how they work

Call getGrade(73)
→
Parameter average = 73
→
Body runs
→
return "B"

Parameters

Inputs the recipe expects.

Return

The value sent back to the caller.

Real world

calculateTax(price), formatName(user).

Live coding · 10 minutes

From marks to a result object

function summarize(name, marks) {
  let total = 0;
  for (const m of marks) total += m;
  const average = total / marks.length;
  return { name, total, average, grade: getGrade(average) };
}

console.log(summarize("Amina", [80, 90, 70]));

Line by line: loop adds, divide for average, reuse getGrade, return one object.

Type this live. Do not paste a finished file. Pause after the loop and log total.

Recap

What we learned

Why JS

Behavior and calculation the page cannot do alone.

Memory

let / const, types, operators.

Structure

Arrays for lists, objects for labeled records.

Control

if / else, loops, functions that return values.

Common mistakes

  • Using == instead of ===.
  • Adding strings from prompt without Number().
  • Reassigning a const instead of using let.
  • Forgetting arrays start at index 0.
  • Copying a giant calculator instead of writing small functions.

Key takeaways

  1. JavaScript is the behavior layer of the web.
  2. Name values. Prefer const.
  3. Types matter — especially string vs number.
  4. Functions keep logic in one place.
  5. Objects + arrays model real data (students, products, todos).
